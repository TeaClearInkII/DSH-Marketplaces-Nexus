# DSH 万市枢纽

DSH 生态「市场集」面板：聚合展示插件市场、插件市场网站与精选库，支持搜索、筛选与排序。

## 安装

```sh
dsh plugin --profile web add dsh-marketplaces-nexus
```

安装后重启 DSH，进入 设置 → 万市枢纽。更新：`dsh plugin --profile web update dsh-marketplaces-nexus`；卸载：`dsh plugin --profile web remove dsh-marketplaces-nexus`。

完整文档（数据源、启用/禁用、提交新市场、开发信息）：https://github.com/TeaClearInkII/DSH-Marketplaces-Nexus
